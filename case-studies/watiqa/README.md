# WATIQA

> Public project brief · Source code: Private

## Overview

A security-focused record-verification system for individual and bulk queries, audited administration, and role-aware operations.

## Public scope

- Individual and batch record-verification workflows
- Role-based administration and auditable operations
- Security-aware processing for uploaded data

## Selected technologies

TypeScript, Fastify, PostgreSQL, Redis, BullMQ, WebAuthn, ClamAV, and Docker.
