# Private Commerce Platform

> Public project brief · Source code and brand details: Private

## Overview

A multilingual retail experience designed around product discovery, ordering, content management, and customer communication for a regional market.

## Public scope

- Localized product and content experiences
- Customer ordering and support workflows
- Administrative catalog and storefront management

## Selected technologies

React, TypeScript, Express, PostgreSQL, Prisma, Cloudinary, and email integrations.
