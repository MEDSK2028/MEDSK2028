# Apex Funded Bot

> Public project brief · Source code: Private

## Overview

An AI-assisted workflow that turns user-supplied chart screenshots into confirmed, structured trading-journal records and analytics.

## Public scope

- Multi-platform chart interpretation with human confirmation
- Structured journaling across communication and productivity tools
- Analytics synchronization for reviewed trading records

## Selected technologies

Python, Telegram Bot API, vision models, Notion, and Google Sheets.

## Privacy boundary

This brief intentionally omits source code, private repository links, prompts, model-routing logic, trading rules, credentials, deployment configuration, and implementation details.
