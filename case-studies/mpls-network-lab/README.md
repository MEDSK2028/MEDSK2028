# MPLS Network Lab

> Public project brief · Lab files: Private

## Overview

A hands-on networking lab for MPLS, dynamic routing, Linux infrastructure, and security-aware network design.

## Public scope

- MPLS forwarding and service-provider routing concepts
- OSPF and BGP routing scenarios
- Linux-based infrastructure and network-security practice

## Selected technologies

MPLS, OSPF, BGP, Linux, GNS3, VMware, and network-analysis tooling.

## Privacy boundary

This brief intentionally omits lab configuration files, private topology details, addressing plans, device credentials, and implementation walkthroughs.
